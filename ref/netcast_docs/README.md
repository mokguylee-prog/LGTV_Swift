# LG NetCast Reference Documents

Downloaded on 2026-05-23 from LG webOS TV Developer legacy NetCast pages.

## Files

- `NetCast-UDAP.pdf`
  - Primary reference for this project.
  - Covers UDAP discovery/access protocol and service profiles for second-screen controller apps.
  - Source: https://webostv.developer.lge.com/assets/netcast/NetCast-UDAP.pdf

- `NetCast-API.pdf`
  - NetCast API reference, useful background for NetCast 3.0/4.0 platform behavior.
  - Source: https://webostv.developer.lge.com/assets/netcast/NetCast-API.pdf

- `NetCast-Abbreviation_and_Glossary.pdf`
  - LG NetCast terminology reference.
  - Source: https://webostv.developer.lge.com/assets/netcast/NetCast-Abbreviation_and_Glossary.pdf

- `NetCast-Document-Index.html`
  - Local copy of the LG NetCast guide PDF index page.
  - Source: https://webostv.developer.lge.com/more/netcast/guide-pdf

- `NetCast-Platform-Specifications.html`
  - Local copy of the LG NetCast platform specification page.
  - Includes NetCast 4.0 H13/M13 (2013) sections.
  - Source: https://webostv.developer.lge.com/more/netcast/platform-specifications

## Notes

- `NetCast-UDAP.pdf` is the closest official document for 2012/2013 NetCast TV integration.
- The current app code uses the legacy HTTP/XML remote-control path on port 8080.
- `supplemental/` contains community pages referenced by the existing keymap/protocol notes:
  - Home Assistant LG TV support thread: https://community.home-assistant.io/t/workaround-lg-tv-support/8929
  - Home Assistant HDCP request example: https://community.home-assistant.io/t/workaround-lg-tv-remote/188/9
  - B4X LG TV remote app thread: https://www.b4x.com/android/forum/threads/lg-tv-remote-app.27468/page-2
